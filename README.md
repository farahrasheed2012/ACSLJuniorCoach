# ACSL Junior Coach

Single-file SwiftUI macOS app (Sonoma+) for teaching ACSL Junior Division theory and Python to a team, including Soha.

## Open and run

1. Open `ACSLJuniorCoach.xcodeproj` in Xcode 15+.
2. Select the **ACSLJuniorCoach** scheme, destination **My Mac**.
3. Press Run.

All UI lives in `ACSLJuniorCoachApp.swift` (no packages). The Dock/app icon is in `Assets.xcassets/AppIcon.appiconset`.

## What’s inside

- **Coach Dashboard** — Soha only; 5+5 point matrix; 24-point Finals bar; Presentation / Self-Study toggle
- **Contests 1–4** — Slides, live sandboxes, HackerRank I/O + copy-homework
- **Team Mock Exams** — four 5-question short-answer tests and a coach **Reveal Solution Keys** override
